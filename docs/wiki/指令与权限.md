# 指令与权限

## 主指令

主命令是 `/srtp`，可用别名为 `/simprtp`、`/rtp`、`/randomtp`、`/wild` 和 `/wildtp`。

| 指令 | 说明 | 主要权限 |
| --- | --- | --- |
| `/srtp` | 在当前或映射后的世界随机传送自己 | `simprtp.use` |
| `/srtp world <世界> [群系...]` | 在指定世界随机传送 | `simprtp.world`、对应世界权限 |
| `/srtp biome <群系...>` | 在指定生物群系随机传送 | `simprtp.biome` |
| `/srtp location <名称>` | 使用 `locations.yml` 中的范围 | `simprtp.location` 或位置专用权限 |
| `/srtp player <玩家> [世界] [群系...]` | 随机传送其他玩家 | `simprtp.player` |
| `/srtp language [代码/auto/default]` | 查看或选择个人消息语言 | `simprtp.language` |
| `/srtp info [...]` | 查看世界、粒子、形状和效果信息 | `simprtp.info` |
| `/srtp edit ...` | 在线修改传送范围等参数 | `simprtp.edit` |
| `/srtp reload` | 重载主插件与附属插件配置 | `simprtp.reload` |
| `/srtp version` | 查看版本 | `simprtp.version` |
| `/srtp test` | 调试模式下测试效果 | `simprtp.test` |

`simprtp.use` 和 `simprtp.language` 默认向普通玩家开放；管理类权限默认应只授予管理员。`simprtp.*` 包含主要子权限，不建议直接授予所有玩家。

## 绕过权限

- `simprtp.bypass.cooldown`：忽略冷却。
- `simprtp.bypass.delay`：忽略传送前等待。
- `simprtp.bypass.economy`：忽略经济收费。
- `simprtp.bypass.hunger`：忽略饥饿值要求。

## 世界、位置和权限组

- `simprtp.world.*`：允许使用所有已启用世界。
- `simprtp.location.<位置名称>`：在 `locations.yml` 开启权限要求时使用对应位置。
- `simprtp.group.<组名>`：使用 `PermissionGroup` 中相应组的范围参数。

实际部署时应使用权限插件按需要分配，不要依赖玩家名称或 OP 身份做特殊判断。

## 附属插件指令

- `/srtp addons [list/help/version]`
- `/srtp portals <loc1/loc2/create/remove/list>`
- `/srtp magicstick give [玩家]`
- `/srtp party <invite/accept/leave/kick/readyup>`
- `/srtp menu`

只有相应扩展在 `SimpRTPAddons/config.yml` 中启用时，其子指令才会注册。传送门管理权限为 `simprtp.addon.portals`。

## PlaceholderAPI

安装 PlaceholderAPI 后可使用 `%simprtp_count%`、`%simprtp_cooldown%`、`%simprtp_canrtp%`、`%simprtp_price%` 等占位符。带世界参数的形式为 `%simprtp_cooldown_<world_name>%`。完整列表及输出文字位于 `plugins/SimpRTP/placeholders.yml`。
