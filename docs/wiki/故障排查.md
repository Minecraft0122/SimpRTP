# 故障排查

## 插件无法加载

确认以下版本完全匹配：

- Java 25
- Folia 26.1.2
- SimpRTP 4.0.2
- SimpRTPAddons 4.0.2（如果安装）

如果日志提示 SimpRTPAddons 缺少依赖，请确认主插件 JAR 存在且已成功启用。附属插件不能先于主插件或单独加载。

## `/srtp` 不存在

执行服务器控制台的 `plugins`，确认 SimpRTP 为启用状态。当前主命令是 `/srtp`，不再提供 `/brtp` 或 `/betterrtp`。

## 一直找不到安全位置

依次检查：

1. 世界是否列在 `DisabledWorlds`。
2. `MinRadius` 是否小于 `MaxRadius`。
3. `MinY`、`MaxY` 是否符合世界高度。
4. `BlacklistedBlocks` 是否排除了过多常见地表。
5. 生物群系列表是否过窄或名称错误。
6. `Settings.MaxAttempts` 是否过低。

可使用 `/srtp info <世界>` 查看解析后的范围参数。

## 玩家被冷却、收费或饥饿限制

检查 `config.yml` 的 `Settings.Cooldown` 和 `economy.yml`。管理员测试时可临时授予相应的 `simprtp.bypass.*` 权限，不要把绕过权限永久授予所有玩家。

## 出现 Folia 线程所有权错误

4.0.2 已使用 Folia 原生调度器。若错误堆栈来自其他插件，应先更新或移除该插件；若明确指向 SimpRTP，请保存完整启动日志、复现指令、目标世界和配置后提交 Issue。

## 附属插件数据为空

4.0.2 使用 `SimpRTP_Data` 表名，不会自动读取旧 `BRTP_Data`。需要旧数据时，应在停服和备份之后使用 SQLite 工具自行迁移表结构及数据。

## 配置修改没有生效

执行 `/srtp reload`。如果修改了大量世界、数据库或附属模块设置，建议完全重启服务器。YAML 缩进必须使用空格，不能使用制表符。
