# 安装与升级

## 环境要求

- Java 25
- Folia 26.1.2
- SimpRTP 4.0.2
- SimpRTPAddons 4.0.2（可选）

SimpRTPAddons 在 `plugin.yml` 中硬依赖 SimpRTP，因此不能单独运行，且两个 JAR 应使用相同版本。

以下插件只是可选依赖：

- **Vault**：启用经济收费时使用。
- **Essentials**：为传送前位置提供 `/back` 兼容。
- **PlaceholderAPI**：注册 `%simprtp_*%` 占位符。
- **Multiverse-Core**：让多世界插件先于 SimpRTP 加载。

## 首次安装

1. 停止服务器。
2. 将 `SimpRTP-4.0.2.jar` 放入 `plugins` 目录。
3. 如果需要扩展功能，再放入 `SimpRTPAddons-4.0.2.jar`。
4. 启动服务器，等待插件生成配置文件。
5. 执行 `/srtp version` 与 `/srtp info` 检查加载状态。
6. 修改配置后执行 `/srtp reload`，复杂改动建议直接重启服务器。

生成的主要目录如下：

```text
plugins/
├─ SimpRTP.jar
├─ SimpRTPAddons.jar              # 可选
├─ SimpRTP/
│  ├─ config.yml
│  ├─ economy.yml
│  ├─ effects.yml
│  ├─ locations.yml
│  ├─ permissions.yml
│  ├─ placeholders.yml
│  └─ lang/
└─ SimpRTPAddons/
   ├─ config.yml
   ├─ lang/
   └─ data/
```

## 从旧版升级

此分支只面向高版本，没有保留以下兼容行为：

- `/brtp`、`/betterrtp` 指令和 `betterrtp.*` 权限节点已删除。
- 旧后台队列、区块缓存及跨版本依赖已删除。
- 领地插件适配已删除。
- PlaceholderAPI 前缀使用 `%simprtp_*%`。
- 附属插件 SQLite 表名由 `BRTP_Data` 改为 `SimpRTP_Data`，旧附属数据不会自动迁移。

升级前请备份 `plugins/SimpRTP` 和 `plugins/SimpRTPAddons`。建议让 4.0.2 在新的配置目录中生成默认文件，再逐项迁移仍需要的配置，不要直接覆盖回旧版完整配置。

## 卸载

停止服务器后删除对应 JAR。只有确认不再需要配置和数据库时，才删除插件数据目录。
