# SimpRTP 中文 Wiki

SimpRTP 是面向 Folia 高版本服务端的随机传送插件。仓库同时提供两个可独立构建的 JAR：

- **SimpRTP**：主插件，负责指令、权限、随机坐标、安全位置检查、冷却、收费、传送和消息。
- **SimpRTPAddons**：可选附属插件，通过主插件事件扩展传送门、队伍传送、魔法棒、菜单、日志等功能。

当前版本为 **4.0.2**，目标运行环境为 **Java 25、Folia 26.1.2**，两个插件均声明 `api-version: '26.1'` 和 Folia 支持。

## 从这里开始

1. 阅读[安装与升级](安装与升级)，把所需 JAR 放入服务器的 `plugins` 目录。
2. 阅读[SimpRTP 运行机制](SimpRTP-运行机制)，了解一次随机传送如何完成。
3. 如果使用附属插件，阅读[SimpRTPAddons 运行机制](SimpRTPAddons-运行机制)。
4. 根据[配置与性能](配置与性能)调整传送范围、冷却和效果。
5. 通过[指令与权限](指令与权限)分配玩家和管理员能力。

## 重要设计取舍

- 主指令是 `/srtp`；`/brtp` 和 `/betterrtp` 已移除。`/rtp` 仍是通用别名。
- 坐标在玩家发起请求时按需生成，不再维护后台预生成队列。
- 使用 Folia 原生实体、区域、全局和异步调度器，不包含跨版本调度兼容库。
- 不再包含自动更新、统计上报、日志上传或后台区块扫描。
- 不再集成 WorldGuard、Lands、Residence 等领地插件，随机位置不会主动避开领地。

遇到问题时请先查看[故障排查](故障排查)。
