# 配置与性能

## 主配置

`config.yml` 中最常调整的项目：

- `Settings.MaxAttempts`：一次请求最多尝试多少个候选位置。过低可能经常失败，过高会增加单次请求开销。
- `Settings.Cooldown`：冷却时间、是否按世界分别计算，以及传送次数锁定。
- `Settings.Delay`：传送前等待时间及移动取消。
- `Default.MaxRadius` / `MinRadius`：默认随机范围。
- `Default.CenterX` / `CenterZ`：随机范围中心。
- `Default.Shape`：`square` 或 `circle`。
- `Default.MinY` / `MaxY`：安全位置搜索高度。
- `BlacklistedBlocks`：不可作为落脚点的方块。
- `DisabledWorlds`：禁用随机传送的世界。
- `CustomWorlds`：各世界独立范围。
- `Overrides`：将一个世界的请求映射到另一个目标世界。
- `WorldType`：覆盖世界的 `NORMAL` 或 `NETHER` 搜索方式。
- `PermissionGroup`：按权限组使用不同半径与中心。

## 其他文件

- `economy.yml`：Vault 收费、按世界价格及饥饿值消耗。
- `effects.yml`：声音、标题、粒子、药水和传送后无敌。
- `locations.yml`：命名位置范围及其权限要求。
- `permissions.yml`：权限相关配置。
- `placeholders.yml`：PlaceholderAPI 输出格式。
- `lang/*.yml`：服务器默认语言及玩家可选语言。

## 性能建议

1. 保持合理的 `MaxAttempts`。默认 32 适用于大多数世界；危险方块很多或可用群系极少时再谨慎提高。
2. 不要把允许生物群系限制得过窄，否则插件需要尝试更多候选点。
3. 将不需要的粒子、药水、标题和附属扩展关闭。
4. 将 `RTPMenu.AutoRefresh` 保持为 `0`，除非确实需要动态刷新。
5. 不需要传送记录时关闭主插件或附属插件的 Logger。
6. 合理设置冷却，避免玩家短时间内大量触发新区块加载。

## 当前版本不会做的后台工作

4.0.2 没有预生成坐标队列，也不会持续扫描或缓存区块。优点是空闲时几乎没有随机传送后台负载；代价是玩家发起请求时才会加载目标区域并寻找安全位置。

## 领地保护警告

此高版本精简分支已删除 WorldGuard、Lands、Residence、GriefPrevention、Towny 等领地集成。SimpRTP 只判断世界地形是否安全，不判断目标位置是否属于玩家领地。若服务器要求避开领地，需要另行实现事件监听器，在 `RTP_TeleportEvent` 中检查并拒绝或替换目标位置。
